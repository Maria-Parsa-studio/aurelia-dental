# Aurelia Dental

A modern and responsive dental clinic landing page designed with a clean, elegant, and premium visual style.

## Project Overview

Aurelia Dental is a concept website created to demonstrate professional web and landing page design skills.

### Features

* Modern responsive layout
* Premium dental clinic branding
* Hero section with strong call-to-action
* Treatment and pricing sections
* Doctor profiles
* Clinic gallery
* Customer testimonials
* Appointment booking section
* Mobile-friendly design

## Design Focus

The project focuses on user-friendly navigation, clear calls to action, visual hierarchy, and a professional healthcare experience.

## Services Demonstrated

* Web Design
* Landing Page Design
* Responsive UI Design
* WordPress-ready Design
* User-Centered Design
